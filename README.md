# Student Management System

A clean, structured **Command Line Interface (CLI)** application built with Python. This project serves as a foundational demonstration of data manipulation, user input handling, and core programming principles like CRUD (Create, Read, Update, Delete) operations.

## 🚀 Features

- **Add Student:** Register new students with a unique ID, name, age, course, and marks.
- **View Students:** Display a formatted list of all registered student records.
- **Search Student:** Find specific student details instantly using their unique Student ID.
- **Update Student:** Edit existing student details (Name, Age, Course, Marks) seamlessly.
- **Delete Student:** Permanently remove a student record from the system.
- **Analytics:** Calculate and display the real-time average marks of all registered students.

## 🛠️ Tech Stack

- **Language:** Python 3.x
- **Storage:** In-memory Python Data Structures (Dictionaries and Lists)

## 💻 How to Run

1. Make sure you have Python installed on your computer.
2. Clone this repository or download the source code file.
3. Open your terminal or command prompt in the project folder.
4. Run the following command:
   ```bash
   python main.py
   ```
